# تحديث هوية MILO CASHIER — أبيض وأسود وخط عربي أنيق

تم اعتماد أسلوب مستوحى من الصورة التي زودت بها: خلفية رمادية فاتحة، بطاقات بيضاء، نص أسود، أزرار سوداء مستديرة، خطوط عربية رشيقة وظلال هادئة.

الخط المستخدم: IBM Plex Sans Arabic (من Google Fonts). يحتاج اتصالًا لتحميله أول مرة؛ يظل الخط الاحتياطي Tahoma/Arial عند انقطاع الإنترنت. هذا مشابه في الطابع للصورة وليس ادعاءً بأنه الخط الأصلي نفسه.

التحديث شمل جميع صفحات HTML للكاشير، الإدارة، العملاء والمتجر، وكذلك قوالب Skeleton Loading. ملف المظهر الموحد: milo-monochrome.css. تم تحويل ألوان العلامة الخضراء والزرقاء في CSS إلى أحادية اللون مع الإبقاء على الألوان التحذيرية المعنوية. لم يتم تعديل منطق JavaScript أو Google Apps Script.

التركيب: فك الضغط وانشر محتويات المجلد MILO_CASHIER_WITH_BARCODE_LABELS مكان ملفات الواجهة بعد حفظ نسخة احتياطية، ثم أعد تحميل الموقع بدون كاش. لا حاجة لإعادة نشر Code.gs إذا كانت آخر نسخة منه هي المثبتة بالفعل.

تنبيه: لم أجر اختبار قبول فعلي على متصفحك أو اتصال Google Sheets. اختبر صفحات البيع والتقارير والمنتجات والطباعة والإدارة على نسخة تجريبية قبل النشر. بعض النصوص داخل الرسوم البيانية/الأيقونات المضمنة لا تتغير عبر CSS.
