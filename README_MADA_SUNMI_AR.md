- زر شاشة التحصيل أصبح: **دفع مدى — إرسال إلى SUNMI**.
- يرسل قيمة السلة إلى صفحة `milo-sunmi-receiver.html` عبر `miloPayRelay` (بعد إضافة `MILO_PayRelay.gs` وتوجيهه في `Code.gs` ونشر الإصدار).
- يختار وضع **شبكة** ويضبط مبلغ الشبكة بعد نجاح الإرسال، لكن **لا يعتمد الفاتورة تلقائيًا**.

- لم نغير `Code.gs` أو بقية وظائف البيع والطباعة؛ أُبقيت إضافة `MILO_PayRelay.gs` كما هي.
- رفع ملفات ZIP إلى GitHub Pages، ثم تحديث صفحة الجهاز / إعادة التحميل القسري للمتصفح.
- اختبر بمبلغ صغير وتجنب إصدار فاتورة قبل نجاح الدفع الحقيقي.
