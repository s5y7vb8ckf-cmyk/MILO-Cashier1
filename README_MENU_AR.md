# ميلو – ترتيب القوائم بدون تغيير عمل النظام

تم تنظيم القائمة الجانبية بالترتيب:
1. الرئيسية (تفتح مركز التقارير الموجود)
2. المبيعات والعملاء
3. المنتجات والمخزون
4. المشتريات والموردين
5. المحاسبة
6. التطبيقات
7. التقارير
8. الإعدادات

القوائم قابلة للفتح والإغلاق، وتفتح مجموعة الصفحة المختارة تلقائيًا. جميع صفحات ميلو القديمة محفوظة في المجموعات؛ لم تُحذف أي صفحة أو تغيّر مسار خادم/قاعدة بيانات. قسم المحاسبة يجمع الصفحة المالية (بداخلها الأصول الثابتة والقيود اليومية وشجرة الحسابات)، المصروفات، والسندات.

المطبخ والطلبات النشطة وفواتير الجوال ومساعد ميلو ما زالت في ملفات النسخة المرفقة.

## النشر الآمن
- خذ نسخة احتياطية من ملفات GitHub والموقع قبل الاستبدال.
- ارفع ملفات الحزمة كاملة مع المحافظة على بنية المجلدات.
- أبقِ Code.gs الحالي كما هو إن كان قد نُشر وفعّالًا؛ لا حاجة لتغيير الخادم من أجل ترتيب القائمة.
- جرّب تسجيل الدخول والتنقل بين المبيعات/المخزون/المشتريات/المحاسبة/المطبخ على نسخة اختبار أولًا.
- إذا ظهرت الواجهة القديمة، امسح التخزين المؤقت للموقع أو افتح نافذة خاصة ثم أعد تحميل الصفحة.

## حدود الفحص
فحصنا سلامة ملفات JavaScript وتطابق روابط الصفحات؛ لم ننفّذ اختبار بيع فعلي أو اتصال بقاعدة بياناتك أو استضافة GitHub.
