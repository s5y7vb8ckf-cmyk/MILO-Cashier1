# تحديث فتح وإغلاق الوردية — MILO CASHIER

- عند فتح الوردية يظهر مؤشر تحميل أنيق إلى أن ينتهي الحفظ والتحقق من الخادم.
- عند تأكيد إغلاق الوردية تظهر شاشة التحميل أثناء فحص السجلات وحفظ الإغلاق وإعداد التقرير.
- بعد النجاح تظهر علامة صح، وعند الخطأ تظهر رسالة واضحة.
- يمنع تكرار إرسال فتح/إغلاق الوردية أثناء العملية.
- تم الحفاظ على أسئلة التأكيد عند الإغلاق وعلى طباعة تقرير الوردية إن كانت مفعلة.
- لم تتغير ملفات Google Apps Script أو إعدادات ربط الحساب.

## الاختبار
افتح وردية تجريبية ثم أغلقها مع التحقق من سجل الورديات، ومطابقة التقرير، وعدم تكرار الحركة عند الضغط عدة مرات.
