# MILO CASHIER — التحديث التطويري

## الملفات الأساسية
- `index.html`: نظام الكاشير الأصلي بكل شاشاته.
- `app.js`: أضيف تبويب «ميلو الذكي» مع إبقاء الوظائف الأصلية.
- `smart-suite.js`: لوحة تحليل مرتبطة بـ API الأصلي، تنبيهات أولية، استعلامات محلية، تصدير CSV.
- `Code.gs` و`AdminBackend.gs`: ملفات الخادم الأصلية **لم يتم تعديلها**.
- `admin.html`: لوحة الإدارة الأصلية.
- `customer-shop.html` / صفحات الطلبات: المتجر والطلبات من النسخة الأصلية.

## تشغيل
1. فك الضغط وارفع مجلد الكاشير كاملًا على استضافة HTTPS ثابتة أو شغّله عبر خادم محلي HTTP.
2. افتح `index.html`، وسجّل الدخول لحسابك المعتاد.
3. من القائمة اضغط «ميلو الذكي»؛ يتطلب إنترنت وAPI فعّالًا للحصول على الفواتير.
4. راجع رابط API داخل `app.js` وملف Apps Script المنشور قبل استخدام الإنتاج؛ الرابط مستمر كما هو من نسختك السابقة.
5. اختبر نسخة تجريبية منفصلة قبل استبدال موقع البيع الفعلي.

## ما أضيف وجرى تنفيذه فعليًا
- تبويب ميلو الذكي في قائمة الكاشير.
- مؤشرات المبيعات والفواتير ومتوسط الفاتورة في فترة اختيارية.
- مؤشرات مراجعة خصومات عالية والقيم السالبة والباقي غير المتوقع، على قدر البيانات المتاحة.
- تنبيهات انخفاض المخزون عند 5 قطع أو أقل.
- مساعد قواعد محلي لأربع أسئلة محددة؛ **ليس نموذج ذكاء اصطناعي توليدي**.
- تصدير تنبيهات المراجعة كملف CSV.

## موجود مسبقًا في الملفات الأصلية
- نقطة البيع، الفواتير، ملصقات الباركود، الورديات، المنتجات والمخزون.
- وضع عمل محلي ومزامنة وفق حدود النسخة الأصلية.
- برنامج ولاء، طلبات العملاء، ولوحة الإدارة.

## غير مؤكد / يحتاج تكامل أو تحقق قبل الإعلان عنه
- المطابقة النظامية التامة مع جميع متطلبات المرحلة الثانية من هيئة الزكاة؛ ملفات الإيصال الحالية ليست شهادة اعتماد.
- إرسال رسائل واتساب بشكل آلي عبر واجهة أعمال رسمية، وإجراءات الاشتراك والموافقة.
- حارس ميلو كتتبّع أمني لحظي على الخادم، وتحليل خطر متقدم أو إشعارات دفع للمالك.
- مساعد ذكاء اصطناعي توليدي مع تحليل أعمال موثوق واتصال آمن بواجهات الذكاء الاصطناعي.
- استقرار التزامن وقت تضارب المخزون وأمان البيانات والصلاحيات تحت الضغط.

**تنبيه:** لا تتعامل مع مؤشرات الخطر كدليل سرقة. راجع مصدر المعاملة والسياق والصلاحيات.
