# MILO Pay — التفعيل من صفحة الأدوات

1. ارفع ملفات الحزمة إلى GitHub Pages بالطريقة المعتادة.
2. سجّل الدخول إلى الكاشير، ثم افتح **الأدوات**.
3. اضغط **تفعيل ميلو باي**. يعمل التفعيل على المتصفح الحالي للمتجر المسجل فقط.
4. افتح صفحة `milo-sunmi-receiver.html` على SUNMI V2s واستخدم رمز الاقتران.
5. من نقطة البيع > إتمام الدفع، يظهر زر **MILO Pay | ميلو باي**.
6. عند الضغط يرسل مبلغ الفاتورة إلى صفحة MILO على SUNMI عن طريق مسار `miloPayRelay` الموجود بالنسخة السابقة.
7. نفذ الدفع داخل رواء باي يدويًا، وتحقق من إيصال العملية قبل اعتماد الفاتورة في MILO.

## مهم
- يتطلب ملف `MILO_PayRelay.gs` في Apps Script وإضافة مسار `miloPayRelay` ونشر نسخة جديدة من المشروع، كما في `README_SUNMI_RELAY_AR.md`.
- زر التفعيل لا يربط تطبيق رواء باي أو البنك تلقائيًا؛ لا يمكن إثبات نجاح الدفع البنكي عبر صفحة المتصفح هذه.
- التفعيل مخزّن في `localStorage` لهذا المتجر على المتصفح الحالي؛ إذا أردت تفعيلًا موحدًا لكل أجهزة المتجر فهذا يتطلب إضافة إعداد للخادم.
- ملفا `Code.gs` و `MILO_PayRelay.gs` لم يُعدّلا في هذه الحزمة.
- لا تُدخل بيانات البطاقات البنكية في صفحات ميلو.
